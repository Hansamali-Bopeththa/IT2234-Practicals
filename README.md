# IT2234-Practicals

Module and Route Creation
I designed three modules:

  01. Course – Representing individual courses with attributes such as name, credits, code and description.

  02. Degree – Storing details about degree programs offered such as name, department and number of years..

  03. Student – Managing student-related data, including personal details.

For each module, I created corresponding routes (CourseRoute, DegreeRoute, StudentRoute) to define endpoints for handling HTTP requests.

Postman and MongoDB Connection
I linked my application with MongoDB and tested the APIs using Postman, ensuring that data transactions worked as expected.

Executing CRUD Operations
The following operations were successfully executed:

  01. GET requests retrieved data from the database.

  02. POST requests allowed insertion of new records.

  03. PUT requests facilitated updates to existing entries.

  04. DELETE requests removed unwanted data.
