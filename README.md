# IT2234-Practicals

Module and Route Creation
I designed three modules:

Course – Representing individual courses with attributes such as name, credits, code and description.

Degree – Storing details about degree programs offered such as name, department and number of years..

Student – Managing student-related data, including personal details.

For each module, I created corresponding routes (CourseRoute, DegreeRoute, StudentRoute) to define endpoints for handling HTTP requests.

Postman and MongoDB Connection
I linked my application with MongoDB and tested the APIs using Postman, ensuring that data transactions worked as expected.

Executing CRUD Operations
The following operations were successfully executed:

GET requests retrieved data from the database.

POST requests allowed insertion of new records.

PUT requests facilitated updates to existing entries.

DELETE requests removed unwanted data.
